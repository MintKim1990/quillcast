# Quillcast

유튜브 영상의 **자막을 재활용**해서 뉴스레터 · 블로그 초안 · 영상 설명란 · 트윗 스레드 같은
**텍스트 자산으로 자동 변환**하는 크롬 익스텐션.

- 무거운 작업(음성인식·영상 렌더링)은 안 함 → 유튜브가 이미 만든 자막을 **사용자 브라우저에서** 읽음.
- 서버는 LLM 정리 한 번만 (서버리스 + usage 과금 → idle 비용 0).
- 반복 사용: 크리에이터가 영상 올릴 때마다 사용 → 월 구독.

## 현재 단계: P0 — 자막 추출 스파이크

가장 위험한 부분(자막을 진짜 긁어올 수 있나?)부터 검증. 지금 버전은 **자막을 긁어서 화면에 띄우기만** 함.

### 설치 (load unpacked)

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭 → 이 폴더(`C:\git\quillcast`) 선택
4. 아무 유튜브 영상(`youtube.com/watch?v=...`) 열기 → 우측 하단 **📝 자막 가져오기** 버튼 클릭

### 기대 결과

- ✅ 패널에 `[언어: en / 세그먼트: N / 글자수: ...]` + 자막 전문 → **성공**
- ⚠️ "자막 없음" → 그 영상에 자막 트랙이 없음 (말 있는 다른 영상으로 재시도)
- ⚠️ "비어 있음" → 트랙은 찾았는데 YouTube가 timedtext를 막음 → 다음 디버그 대상 (DOM 패널 스크랩 fallback)
- ⚠️ 버튼이 안 뜸 → SPA 타이밍 이슈, 새로고침 후 재시도

> 코드를 고치면 `chrome://extensions`에서 이 확장의 **새로고침(↻)** 눌러야 반영됨.

## 로드맵 (작고 유한)

- **P0** 자막 추출 스파이크 ← 지금 (긁어서 표시)
- **P1** LLM 연결 + 출력 1종 (예: 뉴스레터) — 서버리스 함수 + Gemini Flash
- **P2** 출력 포맷 추가(블로그/설명란/트윗) + 패널 UI 정리
- **P3** ExtensionPay 과금 + Chrome 웹스토어 출시 → 🚀 첫 ship

## 구조

```
manifest.json   MV3 (content script 2개: MAIN world + ISOLATED world)
inject.js       MAIN world — 페이지에서 자막 데이터 읽어 postMessage
content.js      ISOLATED world — 버튼/패널 UI + 결과 표시
panel.css       UI 스타일
```
